# Artwork and visual sources

The current design uses original procedural and vector artwork. It takes inspiration from the scale, depth and motion of the user's Noomo Agency reference, without using that website's models, images or code.

- Hero: three original metallic forms built in Three.js (`js/scene.js`): intersecting square frames, a ribbed sphere and a chain of rounded cubes. Materials are lit using Three.js's bundled RoomEnvironment.
- The Club: actual Unreal development captures. `cape-town.webp` derives from the user's CapeTown_RoadNetwork_4K_final capture. `club.webp` is retained from the existing portfolio. These are development screenshots, not final game footage.
- Hungry Ghost Audio: actual FERAL and REVERB interfaces from the user's existing Audio website source, optimized as WebP.
- Lockstep: a decorative lock-and-orbits illustration authored in HTML/CSS/SVG, not a product screenshot.
- Project index: ten original abstract SVG studies in `js/gallery.js`, illustrating each project's subject. They are decorative artwork, not product logos or interfaces.
- Portrait: retained from the original portfolio.

An earlier orange signal-ring concept was generated with the built-in image generation tool on October 4. That rejected concept remains in source history/scratch material but is not used or included in the public build.
